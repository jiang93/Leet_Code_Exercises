C Programming Language => high-level programming language with low-level capabilities, including pointers, explicit memory access and bitwise operations.
                          It also allows reading from and writing to registers, allowing developers to work closely with computer memory and hardware.

C is often used to develop software that needs to run efficiently and interact with the hardware.

- Operating systems: Unix, Linux and Windows
- Device drivers: allowing OS to communicate with hardware
- Embedded systems: programs that run in devices such as TVs, Cars and household applicances 
- Database systems: DBMS and RDBMS engines

C program structure

1. header files => contains C built-in function declarations, macros and constants that can be used in multiple sources code files
   #include <stdio.h> 

2. Constants => a fixed value that can be defined using const and #define
   Macro and constants => macro defines a replacement text used to represent a value, text and expression before compilation. 
                          const is used to define a read-only variable.
   #define PI 3.142 // define a macro
   #undef PI // remove a macro
   # define PI 3.14 // redefine macro again

   const double PI = 3.142; // defines a read-only variable 
   PI = 3.14; // invalid: pi is const that cannot be modified after initialization

   const qualifiers in different contexts:
   const qualifiers helps to prevent unintentional changes to variables

   1. constant variable => fixed value cannot be changed after initialization [const int a = 10]
   2. pointer to constant => pointer points to a constant variable [const int *p = &x]
   3. constant pointer to variable => constant pointer points to a variable [int *const p = &x]
   4. constant pointer to constant => constant pointer points to constant variable [const int *const p = &x]

3. global variables => variables declared outside all functions, can be accessed by functions in the same source code file.
                       can also accessed across source files
    int counter = 0; # creates and initializes a variable
    static int count; = 0 # creates and restricts variable to its own source code file
    extern int count; # declare variable exists elsewhere 

4. function declarations (user-defined functions) => introduce function name, return type and paraters parameter to the complier before the function is called. 
int add(int a, int b);

5. main function => entry point of the C program where program execution begins.
int main(void) {
    return 0;
}
6. function definitions => contain the code that executes when a function is called.
int add(int a, int b){
    return a + b;
}

Preprocessor directives begin with #. They tell preprocessor to include file contents (#include), expands macros(#define) and select code for compilation(#ifdef, #if). 

#undef => remove a macro
#ifdef => include code if macro is define 
#ifndef => include code if macro is not define
#if => include code if processing condition is true
#elif => check another processing condition  
#else => include alternative conditional code
#endif => end the conditional section
#error => report compilation error
------------------------------------------------------------------------------
#include <stdio.h>
#define MAX_LEVEL 1

#ifndef MAX_LEVEL
#define MAX_LEVEL 100
#endif

int main(){
    #if MAX_LEVEL == 1
        printf("Low level");
    #elif MAX_LEVEL == 100
        printf("high level");
    #else
        printf("invalid level");
    #endif
    return 0;
}

Compiling and running C program
1. code editor => write the .c source code file
2. complier => convert C source code into machine code for CPU to execute the instructions
    - GCC => popular open source C complier on Windows, macOS, and Linux
    - clang
    - Microsoft Visual C++ => IDE which provides code editor, debugging tool, complier and terminal
3. terminal => input command to compile and run the program

Compilation process in C => compile source code to machine code for CPU to execute and perform operations

    
source file => preprocessor (include header file content, replace macro by their values, remove comments and handle directives)
main.c      => main.i
                            => complier (translate source code into assembly code)
                            => main.s
                                        => assembler (translate assembly code into object file containing machine code)
                                        => main.o    
                                                    => linker (link all object files with required libraries and startup code)
                                                    => main.exe

2. multiline => /**/

Identifiers in C => name used to identify a variable, function, label, Enum or user-defined element.
1. must start with alphabet or underscore

Scope of identifiers in C:

2. Local identifier (internal identifier) => inside a function 

Basic Data Types and Format Specifiers in C [ranges are affected depending on the compliers and CPU architecture]:

- Character => %c [8 bits by default, can be signed and unsigned] (char a = 'A')
- String => %s [depend on array size, terminate with '\0'] (char word[] = "hello", char word[6] = "hello")
- Signed integer (int) => %d/ %i(printf), %d(scanf) [32 bits, -2^31 to 2^31-1] (int a = 11)
- Unsigned integer (unsigned int) => %u [32 bits, 0 to 2^32-1] (unsigned int a = 11U)
- Float => %f [32 bits, -3.403 × 10^38 to 3.403 × 10^38] (float a = -1, float a = 1.0, float a = 2.0f)
- Double => %f(printf)/ %lf(scanf) [64 bits, −1.798 × 10^308 to 1.798 × 10^308] (double a = 20, double a = -20.0)
- Long => %ld/ %li [32 bits, -2^31 to 2^31-1] (long a = 2000, long a = 2000L)
- Unsigned long => %lu [32 bits, 0 to 2^32-1] (unsigned long a = 1000, unsigned long a = 1000UL)
- Long double => %Lf [64 bits in MSVC] (long double a = 120000, long double a = -120000.0L)
- Long long => %lld/ %lli [64 bits, -2^63 to 2^63-1] (long long a = -1400000, long long a = -14000000LL)
- Unsigned long long => %llu [64 bits, 0 to 2^64-1] (unsigned long long a = 1400000, unsigned long long a = 14000000ULL)
- (void*) => %p [pointer value/ memory address]

Linkage in C:
- linkage defines how variables/ functions are linked by the linker 
- linkage controls whether a variable/ function is limited to one file or share across multiple files

1. Internal linkage => variables/ functions are accessed within the same file where they declared 
                       [static (used outside functions) seperates variables/ functions in different files]
                       [Retains a local variable value between calls (used inside functions)]
2. External linkage => variables/ functions are accessed from another source file [extern declares a variable/ function defined in another file] 

stdio.h => printf, scanf, fprintf, fscanf

2. Enumerated types [enum]
3. Void type [void]

enum => defines a custom type and assigns names to fixed integer values.

struct => defines a custom type that groups related variables (members) together. Members can have different data types.
union => a special case of struct whose members share the same memory. It stores one member value at a time.

void => represents no value
1. void function_name() => function returns no value
2. int main(void) => function takes no arguments 
3. void* ptr => pointer that points/ stores the memory address without specifying the data type.

The data type of a variable determines what value it can stored and how it is stored, a literal is the value written diectly into the code, it also has a data type.
Both determine how arithmetic is performed.

1. integer literals => 200, 200U, 200L, 200UL, 200LL, 200ULL, 0310, 0xC8, 0b11001000
2. float literals => 200.0f, 200.0F, 2e+2f, 2E+2f, 2e+2F, 2E+2F

   - "hello\n" string literal

Integer Promotion for Arithmetic Operations in C
C programming complier applies integer promotion to covert smaller integer types, such as char, short to int/ unigned int before carrying out arithmetic operations.

Type Coversion and Casting in C:

- Conversion => convert a variable to a data type automatically
1. double a = 20;

- Casting => explicitly converting a variable from one type to another type 
1. data_type var2 = (data_type) var1
   int a = 20;
   double b = double(a)；

2. stdlib.h => data_type var2 = atoi(var1)/ itoa(var1) [ASCII <=> Integer]
   int a = atoi("20");

Operators in C:

1. Arithmetic [addition => +, subtraction => -, multiplication => *, division => /, modulus => %]
2. Relational [equal => ==, not equal => !=, greater than => >, smaller than => <, greater or equal to => >=, smaller or equal to => <=]
3. Logical [and => &&, or => ||, not => !]
4. Bitwise [AND => &, OR => |, XOR => ^, complement => ~, left shifter => <<, right shifter => >>] 
5. Assignment [=, +=, -=, *=, /=, %=, <<=, >>=, &=, |=, ^=]
6. Unary [increment => a++, ++a, decrement => a--, --a, unary operations => [+a, -a, !a, ~a, &a, *a], sizeof]
   int a = 5;
   int b = a++; //postfix increment, a = 6, b = 5

   int c = 5;
   int d = ++c; //prefix increment, c = 6, d = 6 

7. Ternary (shorthand if-else/ if-else if-else, nested if-else) 
- if-esle [condition ? if_value_true : if_value_false]
- if-else if-else [condition1 ? if_value_true
                   : condition2 ? if_value_true
                   : if_value_false]
- nested if-else [condition1 ? condition2 ? if_value_true : if_value_false
                  : condition3 ? if_value_true : if_value_false]
