Bootstrap => Open-source frontend framework that provides responsive layouts and reusable CSS and JavaScript components, making web development easier and faster.

Advantages of using Bootstrap:
1. Easy to use
2. Responsive features adapts to different screen sizes such as phones, laptops, and desktops
3. Browser compatibility with all major modern browsers
4. Customizable, it allows developers to modify Bootstrap’s default styles

Two ways to use Bootstrap:
1. Include Bootstrap from a CDN
   CDN servers are located in different parts of the world which reduce the load on the application server and may improve the loading speed.
   However, the website may lose its Bootstrap styling and functionality if CDN is unavailable or inaccessible.

<!-- include the Bootstrap’s CSS and JavaScript -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Bootstrap demo</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
  </head>
  <body>
    <div class="container">
        <h1>Hello, world!</h1>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous"></script>
  </body>
</html>

2. Download Bootstrap and host it on the application server
   Developers have the full control over the Bootstrap files.
   But Bootstrap uses the application server's bandwidth and increase its traffic. Bootstrap updates must be managed manually.

                Approach                            Suitable for                          Update
   -----------------------------------|----------------------------------------------|---------------------------------------|
   Download compiled files manually	  | Simple websites                              | Download & replace updates manually   |
   -----------------------------------|----------------------------------------------|---------------------------------------|
   Install Bootstrap using npm	      | Larger projects(greater frontend complexity) | Install bootstrap@latest using npm    |
   -----------------------------------|----------------------------------------------|---------------------------------------|

<!-- include the Bootstrap’s CSS and JavaScript -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Bootstrap demo</title>
    <link href="{{ url_for('static', filename='bootstrap/css/bootstrap.min.css') }}" rel="stylesheet">
  </head>
  <body>
    <div class="container-fluid">
        <h1>Hello, world!</h1>
    </div>

    <script src="{{ url_for('static', filename='bootstrap/js/bootstrap.bundle.min.js') }}"></script>
  </body>
</html>

1. viewport meta tag, 
   name="viewport" => tells mobile browsers how to display the page
   width=device-width => page width match the device’s screen width
   initial-scale=1 => display the page at its normal zoom level when it first loads

2. Containing element wrap site content 
   - .container class provides a responsive fixed width container
   - .container-fluid provides full width container, spanning the entire width of the viewport

3. Grid => responsive layout system used to arrange content. It consists of rows and columns. Each row allows up to 12 columns. 
<body>
    <div class="container-fluid mt-3">
        <div class="row">
            <div class="col-md-2 bg-primary text-white">.col</div>
            <div class="col-md-2 bg-dark text-white">.col</div>
            <div class="col-md-2 bg-primary text-white">.col</div>
        </div>
    </div>
</body>

4. Typography
- heading/ jumbotron => <h1> to <h6>
- smaller text => <small>
- highlight => <mark>
- abbreviation => <abbr>
- blockquote => <blockquote>
- description list => <dl>, <dt>, <dd>
- ordered/ unorder list => <ol>, <ul>, <li>
- keyboard input => <kbd>
- grouping of texts => <span>

5. Table 
- <table>, <thead>, <tr>, <th>, <td>

6. Image
- <img src="name.jpg" alt="alternative text">

7. Button/ Alert Button
- <button> (more flexible)/ <input type="button">

8. Form 
- <form action="url_receiving_form_data" method="post">
